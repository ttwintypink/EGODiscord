# EGODiscord — Система тикетов набора в клан EGO (Rust)

Production-ready Discord-бот на **discord.py 2.0+** для управления заявками на вступление в клан EGO и в модерацию Rust-сервера.

## Возможности

- 🎫 **Система тикетов** с выпадающим меню (Dropdown) — набор в клан / в модерацию
- 📝 **Модальные формы** с настраиваемыми вопросами (включая SteamID)
- 🛡️ **Автоматическая проверка Steam** (VAC-баны, часы в Rust, приватность профиля)
- 🤝 **Взятие в работу** (Claim) с ограничением прав и замером скорости реакции
- 🎙️ **Обзвон** — автоматическое создание голосового канала с одноразовым приглашением
- 🔇 **Умный мут** — автоматическое глушение кандидата при перебивании офицера
- 🔒 **Закрытие с подтверждением** — принять / отклонить с указанием причины
- ⭐ **Оценка сервиса** — 5 кнопок-звёзд в ЛС кандидату
- 📜 **HTML-транскрипты** (как у TicketTool) + TXT анкеты, отправляются в логи
- ♻️ **Восстановление тикета** одной кнопкой из канала логов
- 🚪 **Авто-закрытие тикета** при выходе пользователя с сервера
- ⏰ **Анти-неактивность** — предупреждение за 1 час до авто-закрытия (24ч + 1ч)
- 🔔 **Напоминание о Claim** — повторный пинг ролей через 30 минут
- 📋 **Blacklist** — блокировка пользователей по Discord ID
- 📊 **Статистика рекрутеров** — ТОП по количеству, средней оценке и скорости реакции
- ⚙️ **setup-voprosy** — изменение вопросов анкеты прямо из Discord

## Технический стек

- Python 3.10+
- discord.py 2.0+
- aiosqlite (асинхронная SQLite)
- aiohttp (Steam Web API)

## Установка

```bash
git clone https://github.com/ttwintypink/EGODiscord.git
cd EGODiscord
pip install -r requirements.txt
```

## Настройка

### Способ 1 (рекомендуется): переменная окружения `DISCORD_TOKEN`

Этот способ **не позволяет токену попасть в Git** — GitHub автоматически
блокирует пуши, содержащие Discord Bot Token, через Secret Scanning.

**Локально:**
```bash
cp .env.example .env
# Откройте .env и подставьте токен:
# DISCORD_TOKEN=ваш_токен_бота_здесь
```

**На хостинге:** задайте переменную окружения `DISCORD_TOKEN` через панель
хостинга (раздел "Environment Variables" / "Переменные окружения").

### Способ 2 (не рекомендуется): через `config.json`

Впишите токен прямо в `config.json` в поле `"token"`. Этот способ работает,
но при попытке запушить файл в публичный репозиторий GitHub заблокирует пуш.

### Проверка остальных настроек

Откройте `config.json` и проверьте ID каналов, категорий и ролей —
они уже заполнены под ваш сервер. Steam API ключ вшит в конфиг.

## Запуск

### Локально

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
echo "DISCORD_TOKEN=ваш_токен" > .env
python bot.py
```

### На Railway (рекомендуемый хостинг)

Проект уже подготовлен для Railway — есть `Procfile`, `nixpacks.toml` и `runtime.txt`.

**Пошаговая инструкция:**

1. Зарегистрируйтесь на https://railway.app через GitHub (1 клик).
2. Нажмите **"New Project"** → **"Deploy from GitHub repo"**.
3. Если репозиторий не виден — нажмите "Configure GitHub App" и выдайте Railway
   доступ к репозиторию `ttwintypink/EGODiscord`.
4. Выберите репозиторий `ttwintypink/EGODiscord` → ветка `main`.
5. Railway начнёт сборку. Пока она идёт — добавьте переменные окружения:
   - Откройте проект → вкладка **"Variables"** → **"New Variable"**
   - Name: `DISCORD_TOKEN`
   - Value: ваш токен Discord-бота
6. Railway автоматически запустит бота после сборки.
7. Вкладка **"Deployments"** → текущий деплой → **"Logs"** — смотреть логи в реальном времени.

**Бесплатный лимит:** $5 кредита в месяц хватит на ~3 недели непрерывной работы бота.
Когда кредит закончится — бот остановится. Можно привязать карту (платный тариф)
или создать новый аккаунт.

**Примечание:** На Railway файл `database.db` создаётся в контейнере заново при
каждом деплое. Если хотите сохранять данные между деплоями — подключите
Railway Volume (вкладка "Settings" → "Volumes") и поправьте `DB_PATH` в `database.py`.

## Команды

### Пользовательские
- (Нет — все взаимодействия через панели и кнопки)

### Модераторские (префикс `.`)
- `.voice` — создать голосовой канал для обзвона в текущем тикете
- `.stats` — ТОП рекрутеров со средней оценкой и скоростью реакции

### Админские
- `.blacklist add <ID>` — добавить пользователя в чёрный список
- `.blacklist remove <ID>` — удалить из чёрного списка
- `.blacklist list` — показать список
- `.setup-voprosy` — изменить вопросы анкеты

### Разработчика (скрытые, только для ID `1105559182624694393`)
- `.setup` — установить панель тикетов в текущем канале
- `.call <текст>` — отправить кандидату сообщение в ЛС от имени разработчика

## Архитектура

```
EGODiscord/
├── bot.py                  # Точка входа
├── config.json             # Все настройки и ID
├── database.py             # Инициализация БД и SQL-запросы
├── requirements.txt
├── cogs/
│   ├── tickets.py          # Создание тикетов, панели, модалы
│   ├── ticket_control.py   # Кнопки управления, обзвон, закрытие
│   ├── moderation.py       # blacklist, stats, setup-voprosy
│   └── developer.py        # .call, .setup
└── utils/
    ├── embeds.py           # Фабрика Embed-сообщений
    ├── steam_api.py        # Парсинг SteamID и запросы к Steam API
    └── transcripts.py      # Генерация HTML-транскриптов
```

## Безопасность

- Антиспам: один активный тикет на пользователя
- Blacklist: проверка при создании тикета
- Изоляция тикета: права только для кандидата и персонала
- Persistent Views: кнопки работают даже после перезапуска бота
